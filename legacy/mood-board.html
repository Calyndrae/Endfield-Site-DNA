05 / interface and rendering rules

From click
to character.

Reference code included
01 / INDEX

Filter and reveal

Class and Element dropdowns filter the 33-operator array. Clicking a card resolves its index in the full list and fades to the detail view in 0.3s. Names shrink via canvas text measurement after fonts load.

02 / STAGE

Image to video

The homepage offers a 2D illustration/3D display switch. Character motion is pre-rendered enter→idle MP4, composited transparently in WebGL from side-by-side colour and alpha halves. Canvas2D is the fallback.

03 / PAGE GRAPH

Depth-one paths

“All Operators” opens /en-us/operator in a new tab. News links lead to /en-us/news or a news detail. The homepage also opens one official external announcement URL.

Other site sections load Three.js and binary models, but the operator character clip system should not be described as a live Three.js character renderer. The rendering distinction is important when recreating the page feel.
